# 1.4.0 — 서식 있는 본문 (표 · 스크린샷 · 로그 블록)

교대 인수인계에서 가장 많이 들은 말은 "표를 붙이면 다 깨진다", "스크린샷은 첨부로 따로
열어야 한다"였습니다. 이 판은 **인수인계 내용 · 댓글 · 운영 지식**(1차)과 **할일 설명 ·
할일 댓글**(2차)에 표 · 그림 · 로그 블록 · 링크 · 서식을 넣을 수 있게 합니다.

지킨 것이 더 중요합니다 — 옛 글 · 검색 · Excel · 버전 · 인수 확인 · 열람 그룹 경계는
그대로입니다. 설계와 근거는 `RICH_TEXT.md`, 시험 결과는 `VERIFICATION_1.4.0.md`.

## 한 줄 요약

| 영역 | 1.3.1 | 1.4.0 |
|---|---|---|
| 본문 | 줄바꿈만 되는 텍스트 | 표(병합 · 열 너비) · 그림 · 로그/코드 블록 · 체크리스트 · 링크 · 글자색 · 강조 |
| Excel 표 붙여넣기 | 탭 문자로 깨짐 | **표 그대로** |

| 로그 | 줄이 밀리고 공백이 사라짐 | 고정폭 블록 · 줄 접기/가로 보기 · **복사 버튼** · `<script>` 도 글자 그대로 |
| 댓글 | 텍스트 | 본문과 같은 서식(도구는 간단하게). **써도 고쳐도 버전 · 확인 상태 그대로** |
| 서식만 바꾸면 | — | 새 버전은 생기지만 **재확인을 요구하지 않음**(사용자 결정) |
| 메뉴 | — | **늘지 않음** |

## 1. 쓰는 사람에게 보이는 것

- **도구 줄**: 굵게 · 글머리 목록 · 번호 목록 · 체크리스트 · 표 · 그림 · 로그/코드 · 링크 ·
  되돌리기 · 다시 실행 · **더 보기**(기울임 · 밑줄 · 취소선 · 글 속 코드 · 제목 크게/작게 ·
  인용 · 구분선 · 글자색 · 강조) · **미리보기**.
- 표를 누르면 행/열 추가 · 삭제 · 셀 합치기/나누기 · 머리글 행이, 그림을 누르면 크기(25~100%) ·
  설명 · 원본 받기 · 빼기가, 로그 블록을 누르면 종류(로그 · HTTP · JSON · SQL · PowerShell · Shell ·
  정규표현식 · XML · Python · 일반 텍스트)가 그 자리에 나옵니다.
- 그림을 올리는 동안 저장 버튼이 잠기고 '그림 올리는 중… (n)' 이 보입니다.
- 쓰던 내용이 있는데 창을 닫거나 다른 메뉴로 가면 확인을 묻습니다(새로고침 · 탭 닫기 포함).
- 운영 지식 '표준 양식 넣기' 는 이제 제목 · 번호 목록이 있는 서식으로 들어갑니다
  (이미 쓴 내용이 있으면 바꿀지 먼저 묻습니다).

## 2. 읽는 사람에게 보이는 것

- 표는 화면이 좁으면 표만 가로로 밀립니다(본문 전체가 밀리지 않습니다).
- 그림을 누르면 크게 보기(화면 맞춤 / 원래 크기 / 원본 받기). Esc 는 크게 보기만 닫습니다.
- 로그 블록 오른쪽 위에 **복사**. 복사한 내용은 원문 그대로입니다.
- 옛 글은 지금처럼 줄바꿈 그대로 보입니다.

## 3. 인수 확인(재확인) 규칙

| 바뀐 것 | 새 버전 | 재확인 |
|---|---|---|
| 글자 · 표 칸 · 목록 · 로그 블록 내용 | 생김 | 요청 |
| 그림 추가 · 삭제 · 교체, 링크 주소 | 생김 | 요청 |
| 굵게 · 색 · 강조 · 제목 크기 · 그림 너비 · 표 열 너비 | 생김 | **요청 안 함** |
| 댓글 쓰기 · 고치기 · 지우기 | **안 생김** | **요청 안 함** |

버전 비교 화면에는 '내용 서식: 표 1 · 그림 2 · 로그·코드 1' 처럼 요약이 나옵니다.

## 4. 바뀌지 않은 것 (호환성)

- **옛 글은 하나도 바꾸지 않습니다.** 마이그레이션은 칼럼만 더합니다. 누가 고칠 때 처음 서식이 생깁니다.
- **검색 · Excel · RAG** 는 지금처럼 텍스트 칼럼을 읽습니다. 서버가 서식에서 텍스트를 다시
  뽑아 저장하므로 표 칸 내용과 그림 설명도 검색됩니다. Excel 에는 표가 `칸 | 칸 | 칸` 줄로 나갑니다.
- **Excel 가져오기**는 지금처럼 텍스트 글을 만듭니다.
- **버전 복원** · **운영 지식 판 복원**은 서식까지 함께 되돌립니다. 본문에서 뺀 그림도 파일이
  남아 있어 옛 판을 복원하면 다시 보입니다.
- **옛 API 클라이언트**는 `content` / `body` 만 주고받아도 지금처럼 동작합니다.
- 제목 · 비고 · 태그 · 개인 메모 · 일정 설명 같은 짧은 입력은 그대로 텍스트입니다.

## 5. 보안

- 서식 구조는 서버가 **허용 목록으로 검사하고, 목록 밖이면 거절**합니다(스크립트 · 이벤트
  속성 · `javascript:` 링크 · 외부 그림 · 임의 CSS 가 들어올 길이 없음).
- 화면은 구조를 React 요소로 직접 그립니다 — HTML 문자열을 끼워 넣는 곳이 없습니다.
- 본문 그림은 Base64 로 저장하지 않고 **기존 첨부 저장소**에 둡니다. 요청마다 그 글의
  열람 권한을 다시 확인하고(**관리자도 소속되지 않은 제한 그룹은 못 봄**), 캐시에 남기지 않습니다.
- 댓글 그림은 그 인수인계의 권한을 그대로 따릅니다.
- 저장 전 그림은 올린 본인만 보고, 24시간 안에 저장하지 않으면 지워집니다.
- 그림 형식은 파일 내용으로 판정(PNG · JPEG · GIF · WEBP, SVG 제외), 백신 검사 설정이 있으면 똑같이 검사.
- 감사로그에는 본문 원문 · 그림 대신 요약(노드 · 그림 · 표 · 로그 블록 개수)만 남습니다.

자세한 내용: `SECURITY.md` 10-5.
