# 편안한 화면 — 근무에 맞춘 밝기 · 글자 크기 (1.4.1)

4조 2교대로 하루 종일, 밤에는 어두운 관제실에서 이 화면을 본다. 이 판은 기능을 더하지 않고
**오래 봐도 덜 피곤한 화면**을 목표로 했다. 무엇을 왜 바꿨는지, 무엇을 일부러 바꾸지 않았는지 적는다.

---

## 1. 바꾸기 전에 본 것

| 관찰 | 근거 |
|---|---|
| 밝은 화면 하나뿐 — 새벽에도 흰 패널 | 다크 모드 · 저조도 설정 없음 |
| 글자가 작다 | 기본 13px, 가장 많이 쓰는 글자 12px(310곳) · 11px(115곳) |
| 경고 상자 5곳의 배경이 그려지지 않음 | `bg-state-urgent-soft` 가 색 설정에 없었다(기존 결함) |
| 서식 본문의 주황 · 초록 글자가 흰 바탕에서 약함 | 대비 3.6:1 · 3.3:1 (기준 4.5:1) |
| '대기' 상태색이 회색 바탕에서 기준에 조금 못 미침 | 4.37:1 |

대시보드 순서(인수 확인 · 교대 마감 점검이 맨 위)와 메뉴 구성은 이미 맞게 되어 있어 **손대지 않았다**.

## 2. 설계

### 한 가지만 눈에 띄게: 화면이 근무표를 따라간다
상단 바의 **화면 설정**(해/달 아이콘)에서 밝기를 고른다.

| 밝기 | 동작 |
|---|---|
| **근무에 맞춤**(기본) | 근무 설정의 **자정을 넘는 교대**(기본: 야간 18:00~09:00) 동안 야간 화면, 그 밖에는 주간 화면. 1분마다 시각을 다시 봐서 교대 시각에 맞춰 바뀐다 |
| 밝게 / 어둡게 | 시각과 관계없이 고정 |

근무 시간은 관리자 → 교대 시간에서 바꾼 값을 그대로 따른다(새 설정 화면을 만들지 않았다).

### 색
야간 화면은 검정 + 형광색이 아니라 **지금 쓰는 청록을 어둡게 내린 색**이다. 낮과 밤이 같은
제품으로 보여야 하고, 색은 상태(긴급 · 지연 · 확인 필요)에만 써서 밤에 그것만 눈에 띄게 한다.

| 이름 | 주간 | 야간 |
|---|---|---|
| 바탕 | `#f2f6f6` | `#0c171b` |
| 패널 | `#ffffff` | `#12222a` |
| 선 | `#d8e2e4` | `#29414a` |
| 글 / 보조 글 | `#18323a` / `#50646c` | `#d6e0df` / `#a6b8bc` |
| 기준색 | `#08685e` | `#4dbcaa` (그 위 글자는 짙은 색) |
| 긴급 | `#b52637` | `#ff8f99` |

모든 글자색이 패널 · 바탕 위에서 **4.5:1 이상**(야간 긴급 7.5, 확인 필요 9.1, 보조 글 7.9).
E2E 가 야간 화면에서 긴급 글자 대비를 실제로 재서 확인한다.

색은 CSS 변수(`index.css` 의 `:root` / `[data-theme='dark']`)에서 오고 Tailwind 클래스 이름은
그대로다(`bg-surface`, `text-ink` …). 그래서 화면 코드를 거의 바꾸지 않고 전체가 바뀐다.
오류 · 경고 상자에 쓰던 기본 팔레트 칸(`red-50` · `amber-50` …)도 변수로 바꿔 함께 어두워진다.

야간에는 왼쪽 메뉴의 선택 칸을 칠하지 않는다(옅은 바탕 + 왼쪽 띠). 어두운 화면에서 가장
밝은 덩어리가 되어 계속 시선을 끌기 때문이다.

### 글자
- **맑은 고딕을 그대로 쓴다.** 현장 Windows PC 의 ClearType 힌팅 덕에 13~16px 에서 웹 글꼴보다
  선명하고, 내부망이라 글꼴을 받을 곳도 없다. 글꼴을 바꾸는 대신 크기를 바꿨다.
- 기본(보통)을 1px 키웠다: 본문 13→14px, 작은 글 12→13px, 더 작은 글 11→12px.
- 글자 크기 `작게`(예전 크기에 가깝다, ×0.93) · `보통` · `크게`(×1.12).
  **글자만 커지고 버튼 높이 · 여백은 그대로**라 크게 해도 화면 배치가 흔들리지 않는다.
  브라우저 확대(Ctrl +)와 달리 사람마다 저장된다.
- '크게'에서는 인수인계 목록의 열 너비도 같은 배율로 넓어지고, 화면을 넘는 오른쪽 열은
  가로 스크롤로 본다. 작게 · 보통은 예전과 같이 한 화면에 맞춘다.

### 서식 본문의 색
글자색 · 형광펜은 **저장 값(서버 허용 목록의 hex)을 바꾸지 않고** 보이는 색만 주간/야간에 맞춘다.
야간 형광펜은 짙은 바탕 + 밝은 글자(대비 5.7:1 이상), 주간 주황 · 초록은 한 단계 진하게 보인다.

## 3. 저장과 공용 PC

- 설정은 이 PC 브라우저에 **사람(계정)마다** 따로 둔다. 서버 DB 를 바꾸지 않는다.
- 공용 PC 에서 다음 사람은 앞사람 설정이 아니라 **기본값**(근무에 맞춤 · 보통)으로 시작한다.
- 로그인 화면은 마지막으로 쓴 설정을 따른다. 화면을 그리기 **전에** 정하므로 야간에 흰 화면이
  번쩍이지 않는다(CSP 가 인라인 스크립트를 막으므로 첫 스크립트 맨 앞에서 정한다).
- 근무 시간을 아직 못 읽었을 때(로그인 전 · 첫 실행)는 기본 야간(18:00~09:00)을 쓴다.

## 4. 함께 고친 것
- 경고 상자 5곳(행 오류 · 과거 자료 공개 전환 목록 · 담당자 그룹 밖 경고 · 공개 범위 경고 · 운영 지식 경고)의 배경색이 정의되지 않아 그려지지 않던 것.
- 통계 말풍선이 야간에 글자가 안 보이게 될 것(`text-white` → 반대색).
- 기준색 · 상태색 위의 흰 글자가 야간에 묻힐 것(`text-on-accent`).
- 통합 검색 칸이 야간에 마우스를 올리면 흰색으로 번쩍일 것(`hover:bg-white` → 패널색).
- 서식 편집기에서 '표 넣기' · '링크' 직후 바로 친 첫 글자가 사라지던 것. 편집기가 다음 화면 갱신 때
  커서를 돌려주던 틈이었다(1.4.0 부터). 야간 화면으로 E2E 를 돌리다 시나리오 A 가 표 칸이 밀린 채
  저장되는 것으로 드러났고, 이제 넣는 즉시 커서를 옮긴다.

## 5. 바꾸지 않은 것
- 메뉴 · 화면 배치 · 대시보드 순서 · 목록 밀도 설정(좁게 · 보통 · 넓게).
- 서버 · DB · API. 이 판은 화면 파일만 바뀐다.
- 코드 · 로그 블록은 주간에도 어두운 상자 그대로다.

## 6. 한계 · 다음에 할 것
- 통계 막대 색은 주간 색 그대로다(야간에도 읽히지만 더 맞출 수 있다).
- 입력칸 테두리 대비는 예전과 같다(약 1.3:1). 올리려면 화면 전체 인상이 바뀌어 따로 정해야 한다.
- 설정을 계정에 따라다니게(다른 PC 에서도) 하려면 서버에 저장해야 한다 — 이번에는 하지 않았다.
