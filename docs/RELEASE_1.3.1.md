# 1.3.1 — 운영 편의성 · 운영 지식 · 금고 일괄 열람

1.3.0 에서 쌓은 열람 그룹 · 근무표 위에, 현장에서 걸리던 것들을 고친 판입니다.
고친 것 중 **가장 중요한 것은 고치지 않은 것**입니다 — 업데이트를 올리는 것만으로
과거 자료가 공개되지 않게 막았습니다.

## 한 줄 요약

| 영역 | 1.3.0 | 1.3.1 |
|---|---|---|
| 그룹을 안 고르면 | 내 기본 그룹에만 보인다 | **로그인한 모든 사람**이 본다 |
| 과거 '그룹 미지정' 자료 | — | 그대로 둔다. **관리자가 승인할 때만** 전체 공개로 바뀌고, 되돌릴 수 있다 |
| 설정 화면 | 목록·사전 값에서 깨짐(`m.join is not a function`) | 다 그려진다. 값 하나가 틀어져도 그 줄만 경고로 바뀐다 |
| 감사로그 | 화면을 열 때마다 쌓인다 | 단순 열람은 안 쌓는다(설정으로 켤 수 있다). **막힌 열람·인증·권한·내보내기는 그대로** |
| 비밀번호 | 한 건씩 1분 | 인증 한 번으로 목록을 5분(연장 가능, 연속 15분 상한) |
| 운영 절차 문서 | 없음 | **운영 지식** — 분류·태그·검색·첨부·개정 이력·판 비교·복원·인계 연결 |
| 정기 점검 | 없음 | '점검' 반복 일정의 **회차별 완료**(대시보드 · 교대 마감 점검에 함께) |

## 1. 공개 범위 — 그룹 미지정은 전체 공개

**바뀐 것은 기본값입니다.** 명시적으로 그룹을 지정한 자료의 경계는 그대로입니다.

- 그룹을 고르지 않으면 `visibility=ALL` — 로그인한 모든 활성 사용자가 봅니다.
- 그룹을 하나라도 고르면 그 그룹 구성원만 봅니다. **관리자도 예외가 없습니다.**
- 여러 그룹은 OR(어느 한 그룹에만 속해도 보입니다).
- 등록 화면에서 두 경우를 구분해 보여 주고, 그룹을 고르지 않았을 때 전체 공개로
  저장된다는 것을 그 자리에서 알립니다.

### 과거 자료는 저절로 공개되지 않습니다

`alembic upgrade` 는 **어떤 자료의 공개 범위도 바꾸지 않습니다.** 전환은 관리자가
**관리자 → 열람 그룹**에서 다음을 모두 거칠 때만 일어납니다.

1. 건수와 **공개될 자료 목록**(번호 · 제목 · 관계사 · 작성자)을 본다
2. 민감정보 · 외주 노출 경고를 읽는다
3. 확인 문구 `전체공개로 전환` 을 직접 입력한다
4. DB 백업을 받았다는 확인에 동의한다
5. 바꾼 건이 한 줄씩 남아 **묶음 단위로 되돌릴 수 있다**

되돌리기는 전환 뒤 사람이 직접 그룹을 지정한 건을 건드리지 않습니다.

### 담당자 · 전파 대상이 그룹 밖이면 보내기 전에 알립니다

그룹 제한 글에 그 그룹 밖 사람을 담당자로 넣으면 **그 사람에게만 제한이 풀립니다**
(일을 해야 하므로 열어 줍니다). 막지 않고 저장 전에 누가 그룹 밖인지 보여 줍니다.

그룹 단위 전파도 같습니다. 'A팀 전용' 글을 B팀에 전파하려 하면 미리보기가
"B팀 구성원도 이 글을 읽게 됩니다"라고 보내기 전에 알리고, 보낸 뒤에는 감사 기록에
그때의 공개 그룹과 넘어간 그룹이 함께 남습니다.

이 경고는 **남의 소속 그룹 이름을 알려 주지 않습니다**('다른 그룹 소속' / '소속 그룹
없음'만). 구성원 목록은 관리자에게만 열려 있으므로, 경고를 통해 조 편성을 알아낼 수
없어야 합니다.

### 새지 않는 것을 확인한 길

목록 · 검색 · 통계 · 직접 URL · 전파 · 공동 담당자 · 첨부 다운로드 · Excel 내보내기 ·
알림 · 운영 지식과 그 첨부 — 전부 같은 판정식 하나를 지납니다. 막히면 404 입니다
(403 이 아닙니다 — 있다는 사실도 알려 주지 않습니다).

## 2. 설정 화면

- `m.join is not a function` 을 고쳤습니다. 목록이어야 할 값이 문자열로 들어와 있어도
  화면이 멈추지 않습니다.
- `roster.epoch_date` 가 **날짜 칸**으로 나옵니다(전에는 별칭 편집기로 그려져 깨졌습니다).
- 분류가 늘었습니다: 근무표 · 감사로그 · 비밀번호.
- 모르는 모양의 값은 JSON 으로 그대로 보여 주고 고치지 않습니다.
- **값 하나가 화면 전체를 막지 않습니다.** 그 줄만 경고로 바뀌고 원래 값을 함께
  보여 줍니다. 나머지 줄은 멀쩡합니다.
- 저장이 실패하면 서버가 말한 원인을 보여 주고 **재시도** 단추를 둡니다.
  켜고 끄는 값은 실패하면 서버 값으로 되돌립니다.

## 3. 감사로그

**기존 감사로그는 지우지 않습니다.** 보존 기간과 보관 정리 정책도 그대로입니다.

- 기본으로 안 쌓는 것: 인수인계 **열람 성공** 하나뿐입니다
  (`audit.track_handover_views` 를 켜면 다시 쌓입니다).
- 계속 쌓는 것: 로그인 성공 · 실패 · **계정 잠금**, 계정 · 역할 · 그룹 변경,
  인계 등록 · 수정 · 삭제 · 복구 · 전파 · 확인, 공개 범위 변경, 과거 자료 전환과
  되돌리기, 중요 내보내기, 문서 업로드 · 삭제 · 다운로드, 비밀번호 인증 · 열람 ·
  실패 · 연장, 설정 변경, 백업 · 복구와 그 실패.
- **막힌 열람은 늘 남깁니다.** 남의 그룹 자료를 번호로 찔러 본 흔적이 조사의 출발점입니다.
- **계정 잠금**을 따로 남깁니다(`ACCOUNT_LOCKED`). 실패 기록을 세어 잠긴 시각을
  짐작하게 하지 않습니다.
- 찾기: 중요도별 빠른 보기 네 갈래 — 중요 행위 / 인증 · 권한 / 데이터 변경 / 일반 열람.
  기본 화면은 '일반 열람'을 뺀 상태입니다.

## 4. 운영 지식 (새 메뉴)

SOP · 탐지/분석 가이드 · 비상 대응 · 장비 운용 · 점검 체크리스트 · 참고 자료를
인계와 **같은 DB, 같은 열람 규칙** 안에 둡니다.

- 분류 · 태그 · 제목/본문/태그 검색 · 상단 고정 · 재검토 예정일(지나면 표시)
- 작성자와 **최종 수정자 이름**, 등록/수정 시각
- **개정 이력** — 판올림마다 본문째로 남고, 두 판을 나란히 비교하고, 옛 판으로
  되돌립니다(되돌림도 새 판으로 쌓여 이력이 끊기지 않습니다). 수정 사유를 적을 수 있습니다.
- 삭제는 지운 표시만 하고 **되살릴 수 있습니다**
- **표준 양식**(한 번 누르면 들어갑니다): 목적·범위 / 탐지·확인 기준 / 분석 절차 /
  조치 방법 / 보고·전파 기준 / 후속 확인 / 관련 문서
- 공개 범위는 인계와 같은 규칙(전체 공유 / 그룹 선택). **첨부는 문서의 열람 권한을
  그대로 상속합니다** — 문서를 못 보면 파일 번호를 알아도 못 받습니다.
- 고치는 권한(작성자 · 근무 관리자)과 읽는 범위(그룹)를 따로 둡니다.
- 인수인계와 양방향 연결: 인계 상세의 '관련 운영 지식', 문서의 '관련 인수인계'.
  걸어 둔 것이 없으면 **제목에 쓰인 말로 절차를 추천**합니다(규칙 기반 — AI 를 쓰지 않습니다).
  연결은 열람 권한을 넓히지 않습니다.
- 문서 번호 · 판 번호 · 출처 · 공개 범위를 남겨 두어 뒤에 RAG 에 쓸 수 있게 했습니다.
  **지금은 AI 기능을 넣지 않았습니다.**

## 5. 비밀번호 금고 — 인증 한 번으로 목록 보기

장비 열 대에 접속하려고 열 번 비밀번호를 치게 하면 사람들은 메모장에 적어 둡니다.
그래서 한 번 인증하면 **자기가 볼 수 있는** 비밀번호를 목록으로 보여 줍니다
(관계사 · 장비명 · 접속 방법 · 계정 · 비밀번호, 항목마다 복사).

| 통제 | 값 |
|---|---|
| 기본 열람 시간 | 5분 (설정 1~10분) · 남은 시간 표시 · `5분 연장` · `지금 잠그기` |
| 연속 유지 상한 | **15분** — 설정으로도 넘길 수 없습니다 |
| 남은 시간 판정 | 서버(화면은 20초마다 물어봅니다) |
| 개인 항목 | 등록한 사람만. **남의 개인 비밀번호는 일괄 열람에도 보이지 않습니다** |
| 평문 보관 | 화면 메모리뿐. localStorage · sessionStorage · 로그 · 검색 · HTML 캐시에 쓰지 않습니다 |
| 즉시 가림 | 화면을 떠남 · 로그아웃 · 계정 변경 · **권한 회수**(역할 · 소속 · 계정 비활성) |
| 인증 실패 | 5분 5회로 제한 |
| 감사 | 시작 · 연장 · 잠금 · **실제로 연 항목** · 실패 |
| 공용 콘솔 | 잠글 때 복사해 둔 값을 클립보드에서도 비웁니다 |

한 건씩 보기와 비밀번호 이력은 그대로 있습니다(개별 열람도 1분 → 5분으로 늘고
연장이 생겼습니다).

**그룹 단위 금고 공개는 이번에 넣지 않았습니다** — 야간 단독 근무자가 '내 그룹이
아니어서' 장비를 못 열면 그것이 곧 대응 지연입니다. 검토 결과와 넣기 위한 조건은
`docs/SECURITY.md` 10-3 에 적었습니다.

## 6. 정기 점검 · 교대 마감

**새 메뉴를 만들지 않았습니다.** 점검은 '점검' 종류의 **반복 일정**으로 등록하고,
거기에 **회차별 완료**만 붙였습니다. 할 일 목록이 인계 · 할일 · 점검 셋으로 쪼개지면
야간에 혼자 보는 사람이 어느 목록을 봐야 하는지부터 헷갈립니다.

- 대시보드 **'오늘 점검'**(없으면 자리를 차지하지 않습니다) · 일정 → **정기 점검** 탭
- 담당자를 비우면 근무자 누구나 완료할 수 있고, 누가 했는지 남습니다
- 오늘 끝낸 것이 내일 회차를 끝낸 것으로 만들지 않습니다
- 교대 마감 점검에 **'오늘 점검 미완료'** 가 함께 나옵니다

넣지 않은 편의 기능과 그 이유는 `docs/MENU_MAP.md` 3절에 적었습니다.

## 9. 알려진 제한

- 금고 열람 세션은 **프로세스 메모리**에 있습니다. 앱을 다시 띄우면 모두 잠깁니다
  (의도한 동작입니다). 여러 프로세스로 띄우는 구성은 지원하지 않습니다.
- 운영 지식 본문은 서식 없는 글(텍스트)입니다. 표와 그림은 첨부로 붙입니다.
- 절차 추천은 제목 낱말이 겹치는 정도로만 고릅니다. 안 맞으면 직접 연결하십시오.
