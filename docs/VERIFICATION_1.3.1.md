## 5. 공개 범위 변경이 기존 자료에 미치는 영향

- **지금 당장은 0건.** 패치는 기존 자료의 공개 범위를 바꾸지 않습니다.
- 관리자가 전환을 승인하면, '실제 그룹을 하나도 지정하지 않은' 인계만 바뀝니다.
  명시적으로 그룹을 지정한 자료는 대상이 아닙니다.
- 전환 대상 건수는 설치본마다 다릅니다. 확인용 PostgreSQL 설치본에서는
  미분류에 남은 자료가 **2건**이었습니다(실제 운영 DB 에서 먼저 확인하십시오).
- 전환하면 삭제된 건도 함께 바뀝니다(복구했을 때 범위가 어긋나지 않도록).
  '지금 보이게 되는 수'는 미리보기에 따로 표시합니다.
- 되돌리면 `GROUPS` + '미분류' 로 돌아갑니다. 전환 뒤 사람이 직접 그룹을 지정한 건은
  건드리지 않습니다.
