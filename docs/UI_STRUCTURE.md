# UI_STRUCTURE.md — 화면 구조 / Sitemap / Wireframe

> 디자인 원칙: **Dense · Professional · Information-rich · Low visual noise**
> 큰 Card 남발 금지. 화면 밀도 우선. 색상 단독 의미전달 금지(Icon+Text 병행).

**동작 규칙**
- 행 클릭 → 우측 Drawer. 목록은 그대로 유지(선택 행 하이라이트).
- 좌측 `★`·관계사 컬럼은 Pin(고정), 헤더 Freeze.
- 확인 상태 셀: `✔ v3`(확인 완료·버전 표기) / `⚠ 재확인`(확인 후 변경) / `○ 대기`.
- 정렬은 헤더 클릭(Shift+클릭 = 다중 정렬, 순번 배지 표시).
- 그리드 상태(필터/정렬/컬럼/밀도)는 URL query에 직렬화 → 링크 공유·새로고침 보존.

## 4. 인수인계 Drawer (§72)

```
                                   ┌──────────────────────────────────────────┐
                                   │ #18234        ★  [수정][+할일][⋯]   ✕   │
                                   │ ⛔긴급  진행중  A사        v7 · 10:31    │
                                   │ ─────────────────────────────────────── │
                                   │ SSL VPN 이상징후 확인                    │
                                   │ ─────────────────────────────────────── │
                                   │ 등록일 2026-09-16  수행일 2026-09-17     │
                                   │ 전달자 홍길동   담당자 김철수            │
                                   │ 확인   김영희 ⚠ v5 확인(현재 v7)         │
                                   │ 태그   #SSLVPN #A사 #이상징후            │
                                   │ ─────────────────────────────────────── │
                                   │ [상세][할일 2/5][일정][전달이력][변경이력][첨부 3][댓글 4] │
                                   │ ─────────────────────────────────────── │
                                   │ 상세 내용                                │
                                   │ 09/16 03:12 비정상 인증 시도 다수 …      │
                                   │                                          │
                                   │ 비고                                     │
                                   │ 담당부서 회신 대기                       │
                                   │ ─────────────────────────────────────── │
                                   │ [확인(Ack)]  [상태 변경 ▾]  [인계 담기]  │
                                   └──────────────────────────────────────────┘
```
- 폭 520px(리사이즈 가능, 기억됨). `Esc` 닫기, `j/k` 로 다음/이전 행 이동하며 Drawer 유지.
- 수정 시: 인라인 편집 모드로 전환 + 하단에 `변경 사유(선택)` 입력 → 저장하면 새 버전.
- 다른 사용자가 수정하면 상단에 `⚠ 다른 사용자가 v8로 수정했습니다 [새로고침]` 배지(폴링 30초).

## 10. 키보드 단축키 (§73)

| 키 | 동작 |
|---|---|
| `Ctrl+K` (맥 `Cmd+K`) | 통합검색 팔레트 |
| `Alt+N` | 새 인수인계 — 원안 `Ctrl+N` 은 브라우저가 새 창으로 가져가 페이지에 오지 않는다 |
| `Alt+T` | 새 할일 — 원안 `Ctrl+Shift+T` 는 브라우저가 닫은 탭 다시 열기로 가져간다 |
| `Esc` | Drawer/팝오버 닫기 (창이 먼저 받는다 — 창을 닫을 때 뒤의 Drawer 까지 닫히지 않게) |
| `j` / `k` | 목록 다음/이전 행 (Drawer 가 열려 있으면 Drawer 도 따라간다) |
| `Enter` | 선택 행 Drawer 열기 (버튼·링크에 포커스가 있으면 그것을 누른다) |
| `e` | 수정 모드 |
| `a` | 확인(Ack) |
| `b` | 인계 Basket에 담기 |
| `/` | 그리드 검색창 포커스 (그리드가 없는 화면은 통합검색) |
| `?` | 단축키 도움말 (상단 ⌨ 버튼도 같다) |

키는 글자가 아니라 **키 위치(`KeyboardEvent.code`)** 로 판별한다 — 한글 입력 상태에서 `j` 는 'ㅓ' 로 들어온다.
code 가 비어 오는 입력(원격 조작·가상 키보드)은 글자로, 두벌식 자모는 같은 자리 영문 키로 맞춘다.
입력 필드 포커스 중이거나 대화상자가 열려 있으면 단일 문자 단축키를 비활성화한다(충돌 방지).

## 11. 상태·중요도 시각 표기 (색상 의존 금지)

| 중요도 | 표기 | 상태 | 표기 |
|---|---|---|---|
| 긴급 | ⛔ **긴급** (빨강 테두리 + 굵게) | 신규 | ● 신규 |
| 높음 | ▲ 높음 (주황) | 진행중 | ◐ 진행중 |
| 보통 | 보통 (무채색) | 확인필요 | ⚠ 확인필요 |
| 낮음 | ▽ 낮음 (연회색) | 완료 | ✔ 완료 (행 흐리게) |

확인 상태: `○ 대기` / `✔ v3` / `⚠ 재확인 필요` — 텍스트로도 구분 가능.
