# 1.4.1 — 근무에 맞춘 화면 (야간 화면 · 글자 크기)

오래 봐도 덜 피곤한 화면을 위한 판입니다. **화면 파일만 바뀌고 서버 · DB 는 그대로**입니다.
설계와 근거는 `UI_COMFORT.md`.

## 한 줄 요약

| 영역 | 1.4.0 | 1.4.1 |
|---|---|---|
| 밝기 | 밝은 화면 하나 | **근무에 맞춤**(야간 교대 동안 야간 화면) · 밝게 · 어둡게 |
| 글자 | 기본 13px | 기본 14px, **작게 · 보통 · 크게** (글자만 커지고 배치는 그대로) |
| 설정 저장 | — | 이 PC 의 **사람마다**. 공용 PC 에서 앞사람 설정이 넘어오지 않음 |
| 메뉴 | — | 늘지 않음. 상단 바에 해/달 아이콘 하나 |

## 쓰는 법
상단 바 해/달 아이콘 → **화면 설정**.
- 밝기: `근무에 맞춤`(기본) — 근무 설정의 야간 교대(기본 18:00~09:00)에는 어둡게, 그 밖에는 밝게.
  교대 시각이 되면 저절로 바뀝니다. `밝게` · `어둡게`는 시각과 관계없이 고정합니다.
- 글자 크기: `작게`(예전 크기에 가깝게) · `보통`(기본) · `크게`.

## 함께 고친 것
- 경고 상자 5곳(공개 범위 경고 · 담당자 그룹 밖 경고 · 과거 자료 전환 목록 · 행 오류 · 운영 지식 경고)의 배경이 그려지지 않던 것.
- 서식 본문의 주황 · 초록 글자가 흰 바탕에서 약하던 것(저장 값은 그대로, 보이는 색만 진하게).
- '대기' 상태색 대비를 기준(4.5:1) 위로.
- 서식 편집기: '표 넣기' · '링크' 직후 바로 친 첫 글자가 사라져 표 칸이 한 칸씩 밀리던 것(1.4.0 결함).

## 호환성
- 서버 · DB · API 변경 없음. 마이그레이션 없음.
- 서식 본문 저장 값(글자색 · 형광펜)은 그대로입니다. 보이는 색만 주간/야간에 맞춥니다.
- 목록 밀도(좁게 · 보통 · 넓게), 메뉴, 대시보드 순서는 그대로입니다.

## 배포
`SOC-Handover-1.4.1-patch.zip` — 앱만 교체(Python 라이브러리 · DB 변경 없음).
1.4.0 이 설치된 서버에 `UPDATE.cmd`. 적용 뒤 브라우저에서 **Ctrl+F5**.
되돌리기: 1.4.0 패치를 다시 덮으면 됩니다(DB 구조가 같아 그대로 올라갑니다).

검증 중 드러난 1.4.0 결함: 서식 편집기에서 '표 넣기' 직후 바로 친 첫 글자가 사라져 표 칸이 밀렸다.
야간 화면으로 E2E 를 돌리자 화면 갱신 타이밍이 달라져 시나리오 A 가 매번 실패하며 드러났다. 고친 뒤
쉬지 않고 쳐도 표가 정확한 것을 두 번 확인했고, 전체 E2E 도 통과했다.
