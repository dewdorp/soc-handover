## 2. 요청 시나리오별

### 시나리오 A — 분석 인계 (E2E `test_scenario_a_analysis_handover`, API `TestScenarioA`)
- 편집기에서 행 · 열을 정해 결과표를 만들고, 표 안 도구 · Tab 으로 행을 늘린다.
- WAF 화면 캡처를 **Ctrl+V 이벤트 그대로** 붙여 넣는다(클립보드 파일 → 초안 업로드 → 본문 그림).
- HTTP 로그 블록을 넣고 저장 → 서버 텍스트 칼럼에 `WAF | SQL Injection 의심 | 차단` 줄,
  `[그림]` 자리, **로그 원문 한 글자도 바뀌지 않음**.
- 다른 관제자가 열어 표 · 그림 · 로그를 그대로 보고, 로그 속 `<script>` 가 실행되지 않음
  (`window.__xss_ran` 미설정)을 확인한 뒤 인수 확인 → `ACKED`.
- 표 칸 글이 통합 검색에 걸리고, Excel 에는 표가 글 줄로 나가며 JSON 구조가 새지 않는다.

### 시나리오 B — 댓글 후속 분석 (E2E `test_scenario_b_comment_follow_up`, API `TestScenarioB`)
- 확인까지 끝난 인계에 표 · NDR 캡처가 든 댓글을 쓰고 고친다.
- **원문 버전 그대로 · 인수 확인 `ACKED` 그대로**.
- 그림 크게 보기에서 Esc → 크게 보기만 닫히고 인계 창은 남는다.
  댓글을 쓰다 Esc → 쓰던 글이 남는다(검증 중 발견 · 수정한 결함, 5절).

### 시나리오 C — 옛 자료 호환 (E2E `test_scenario_c_legacy_plain_text`, API `TestScenarioCLegacy`)
- 서식 없는 옛 글이 줄바꿈 그대로 보이고, 일부만 굵게 해 저장하면 텍스트는 그대로 서식만 생긴다.
- Excel 내보내기 · 검색 · 버전 복원(복원하면 다시 서식 없는 글) 정상.
- 옛 API 클라이언트: 글을 바꾸면 서식 없는 글로, 다른 필드만 고치면 **서식 유지**.

### 시나리오 D — 보안 · 권한 (E2E `test_scenario_d_permissions_and_xss`, API `TestScenarioDSecurity`)
- 그룹 제한 인계의 그림: 그룹 밖 사람은 목록 · 본문 · 댓글 · **그림 주소 직접 호출** · 원본 받기 모두 404.
- 그룹에 넣었다 빼면 **그 즉시** 그림이 404(캐시 없음).
- `javascript:` 링크 · 외부 그림 · `onerror` 등 속성 · `<p onclick>` · 임의 CSS → 422.
- HTML · SVG · 텍스트를 `.png` 로 올려도 내용 판정으로 거절.
- 남의 초안 · 볼 수 없는 글의 그림 번호로 끌어오기 → 거절. 볼 수 있는 글끼리 복사 → **복사본** 생성.
- 감사로그에 본문 구조가 아닌 요약(`nodes · images · tables · code_blocks`)만 남는다.

## 6. 확인하지 못한 것 · 한계

- **실제 Excel 프로그램에서 복사한 클립보드**는 시험 환경에서 만들 수 없어, Excel 이 넣는 것과
  같은 형식(HTML 표 + 그림)을 합성해 붙여 넣었습니다. 운영 PC 의 Excel 버전에 따라 셀 서식이
  다를 수 있으나 서식 속성은 붙여넣기 때 모두 지워지므로 표 구조만 들어옵니다.
- 백신 검사 명령(`ATTACHMENT_SCAN_COMMAND`)이 설정된 환경은 시험하지 않았습니다 — 일반 첨부와
  같은 함수(`scan`)를 부르는 것만 코드로 확인했습니다.
- 시험 설치본은 수동 모드입니다. 서비스 모드 설치본의 패치 경로는 1.3.1 과 같은 update.ps1 을
  쓰며 이번에 바뀐 곳이 없습니다.
- 감사로그의 인계 등록 · 수정 기록에는 **기존처럼** 본문 텍스트(`content`)가 남습니다(1.3.1 과 같음).
  서식 구조와 그림만 요약으로 바꿨습니다.
